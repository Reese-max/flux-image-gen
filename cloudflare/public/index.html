Fluxi 是中文 FLUX 圖片產生器，會把白話需求整理成適合簡報、社群、產品與角色創作的出圖 prompt。

中文 FLUX

中文輸入，直接生成 FLUX 圖片。

適合簡報插圖、社群圖、產品概念圖、角色設定與靈感草稿。

必填。請用中文描述主體、場景、風格或用途；按生成圖片後系統會自動整理成 FLUX prompt。

    隱私政策

    Prompt 與圖片會送去哪裡？

    為了整理中文描述與生成圖片，你輸入的 prompt 可能會送到後端、Gemini／Gemma 提示詞服務、NVIDIA FLUX 或 Cloudflare Workers AI。實際使用哪個 provider 取決於目前服務狀態與模型設定。

    本機歷史與雲端保存差異

    本機歷史、風格卡與專案會存在這台瀏覽器的 localStorage。只有你點「存到雲端」並確認後，圖片才會上傳到 Cloudflare R2；metadata 會分開保存為 R2 JSON。

    Prompt 是否公開？

    雲端保存預設不公開、也不保存完整 prompt。只有你在保存前勾選「公開並保存完整 prompt」時，prompt 才會寫入雲端 metadata。

    Cookies、localStorage 與刪除資料

    本站目前主要使用 localStorage 保存教學狀態、本機歷史、風格卡與專案；不需要登入 cookie。你可以在這裡清除本機資料。

    會清除這台瀏覽器中的歷史、風格卡、專案與教學偏好；雲端 R2 作品不會因此刪除。

    是否用於訓練模型？

    本站不主動拿你的 prompt 或圖片訓練自有模型。第三方 provider 如何處理資料，仍以各 provider 的服務條款與資料政策為準。

    授權與商用說明

    模型與 provider 限制

    不同模型與服務商可能有不同使用限制。快速草稿、高品質輸出、Workers AI、NVIDIA FLUX 與未來新增模型，都應以實際 provider 條款為準。

    生成圖能否商用？

    本站不替你保證生成圖可商用、不侵權或適合特定用途。商用前請自行確認模型條款、素材來源、品牌、商標、人物肖像與第三方權利。

    禁止用途

    不得用於違法、詐欺、仿冒證件、侵犯隱私、濫用商標、未成年敏感內容、未授權名人或政治人物高風險素材等用途。

    AI 生成標示建議

    若作品用於公開、商業或新聞脈絡，建議標示為 AI 生成或 AI 輔助創作，並保留 prompt、模型與日期紀錄以便追溯。

    快速教學

    1. 輸入白話中文 先把你想看的畫面用自然中文寫下來，不需要一開始就會英文提示詞。
    2. 轉成專業英文提示詞 使用 Prompt helper 把中文描述轉成更適合 FLUX 的英文提示詞。
    3. 選模型與尺寸 依照速度、品質與用途，選擇 FLUX 模型和方形、橫向或直向尺寸。
    4. 生成、下載、收藏風格卡 按下生成後可下載圖片，也能把常用題材存成風格卡；靈感按鈕與我的風格卡都在生成分頁下方的「靈感」區，點一下即可套用。
